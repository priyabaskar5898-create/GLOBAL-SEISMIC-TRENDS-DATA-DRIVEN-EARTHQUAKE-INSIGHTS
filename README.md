# 🌍 Global Seismic Trends: Data-Driven Earthquake Insights

## Overview

This project analyzes worldwide earthquake data collected from the USGS Earthquake API. Using Python, SQL, and Streamlit, the project cleans, stores, analyzes, and visualizes seismic data to discover earthquake trends and risk patterns.

## Features
* Earthquake data collection using API
* Data cleaning and preprocessing
* SQL-based analytical queries 
* Interactive Streamlit dashboard
  
## Technologies Used
* Python
* Pandas
* Regex
* MySQL
* Streamlit

## Outcomes
* Identified global seismic trends
* Analyzed earthquake-prone regions
* Relational Database Management.

## Domain
Disaster Management | Geoscience | Seismology
